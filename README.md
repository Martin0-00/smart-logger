## Описание плагина
**Smart Logger** — это расширение для Visual Studio Code, которое автоматизирует вставку отладочных логов (`print`, `console.log` и др.) для выделенной переменной с учетом языка программирования открытого файла. Плагин избавляет от рутинного набора однотипного кода для отладки.

## Возможности
* Автоматическое определение языка программирования (`Python`, `JavaScript`, `TypeScript`, `Java`, `C++`, `C#`).
* Генерация синтаксически корректного лога под выбранный язык.
* Вставка отладочного выражения на новой строке с сохранением отступов.

## Горячие клавиши
* `Cmd + Shift + L` (macOS) / `Ctrl + Shift + L` (Windows/Linux) — вставить лог для выделенной переменной.
